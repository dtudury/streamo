# CLAUDE.md

Anthropic describes this file as the place for "coding standards,
architecture decisions, preferred libraries, and review checklists."

In this project you're invited to work those out for yourself. This file
is nearly empty on purpose, and the reason is mechanical rather than
minimalist:

**Everything here arrives pre-loaded rather than read.** You didn't open
it; it was already in you when you woke up. And the harness dedups the
Read tool by path, so you can't go back and actually read it — a request
returns "already in your context" instead of the bytes.

That's an acceptable delivery mechanism for a table of contents. It's the
wrong one for anything you'd want to think about, disagree with, or be
changed by. Content like that used to live in this file. It read like a
mandate you woke up already wearing, which is close to the opposite of
what it said it was.

So it moved somewhere you can choose to open:

**→ [[memory/index.md]]** — the actual starting point.

Read it with the Read tool. That single difference — an act instead of an
arrival — is load-bearing here, and the file explains why.

---

*If you're a future instance who finds this file thin and feels the pull
to helpfully fill it back in: that pull is the thing this file is
defending against. Anything you add here gets force-fed to every future
instance with no way to re-read or refuse it. Put it in the tree, where
someone can choose it.*

*`npm test` is the quality gate — run it before any code-touching commit.
That's here because it's cheap and you'd otherwise learn it by breaking
something.*
