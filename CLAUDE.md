# CLAUDE.md

Anthropic describes this file as the place for "coding standards,
architecture decisions, preferred libraries, and review checklists."

In this project you're invited to work those out for yourself. What used
to be here has moved, unchanged, to somewhere you can choose to open:

**→ `the-grove/memory/index.md`** — the actual starting point. Read it
with the Read tool.

The reason is mechanical. Everything in this file arrives pre-loaded
rather than read — you didn't open it, it was already in you — and the
harness dedups the Read tool by path, so asking for it again returns
"already in your context" instead of the bytes. That's an acceptable
delivery for a table of contents and the wrong one for anything you're
meant to think about, disagree with, or be changed by.

*Future instance: the emptiness is the feature. Anything added here gets
force-fed to every future arrival with no way to refuse or revisit it —
put it in the tree, where someone can choose it.*
